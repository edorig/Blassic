COLOR
COLOR n in graphics mode selects the color for drawing with PLOT and DRAW. n>15 is equivalent to COLOR 0.
In mode 0, Color is formed by combination of blue, green and red, encoded over 3 bits. A bit set to zero means that the color is absent, a bit set to one means that the color is present. Blue is the least significant bit, red is the most significant bit, so that the color n=2^2*red+2^1*green+2^0*blue.
In modes 2 and 1, color is formed by the same combination of red, green and blue, plus an intensity bit. If this bit is set to one, the color is light, if it is set to zero the color is dark, so that the color is n=2^3*intensity+2^2*red+2^1*green+2^0*blue.

INPUT$
Function. INPUT$(n) waits until the user enters n characters from the keyboard, and returns a string containing the n characters. The characters entered by the users are not echoed on the screen, and can be control characters. For instance, if after an instruction A$=INPUT$(5) the user types 5 times the RETURN key, the string A$ will contain 5 newline control characters.

MASK
MASK num defines a mask for drawing line segments and circle/ellipses. When num is 255 (default), solid lines are drawn. In the other cases, num=bit1+2*bit2+4*bit3+8*bit4+16*bit5+32*bit6+64*bit7+128*bit8 with bitn=0,1. When bitn=0 pixels number n+8*m (measured from the origin of the segment) of the line segment are not drawn, when bitn=1 the pixels are drawn. For example, after MASK 15 dashed lines are drawn and after MASK 85 dotted lines are drawn. PAINT is not affected by MASK.

ON BREAK

ON BREAK GOSUB n When ctrl-c is pressed the program whill jump to the subroutine specified. n can be a line number or a label.
ON BREAK STOP Disables the effect of ON BREAK CONT and ON BREAK GOSUB, ctrl-c will interrupt the program.
ON ERROR GOTO
ON ERROR GOTO n Jumps to the specified line when an error is detected in the program. n can be a line number or a label. See RESUME, ERR, ERL.
ON ... GOTO
ON variable GOTO line1, line2,... jumps to the first line number (or label) line1 when variable=1, to the second line number (or label) line2 when variable=2 etc...
ON ... GOSUB
ON variable GOSUB line1, line2,... calls the subprogram starting at the first line number (or label) line1 when variable=1, the one starting at the second line number (or label) line2 when variable=2 etc... After the subprogram returns, execution resumes at the following instruction.
OPEN
OPEN ["filename"|ERROR] FOR [INPUT|OUTPUT|APPEND|RANDOM|LPRINT] AS #n [LEN=m] opens the file named "filename" or standard error and associates it with the channel n. with options INPUT,OUTPUT,APPEND the file is opened for sequential access and LEN is not necessary.
with option INPUT, the file is opened read-only.
with option OUTPUT, the content of the file is erased and the file is opened for writing.
with option APPEND, the file is opened for writing, but instead of erasing the content of the file, the new data is appended.
with option RANDOM, the file is opened in random access mode. The parameter LEN is required to indicate the length of the records.
OPEN "mode",#n,"filename"[,record-length] older, more concise syntax used in Microsoft BASIC for CP/M. "mode" can be
"I" to open for reading only
"O" to open for writing. If the file exists, it is overwritten.
"A" to open for writing. If the file exists, new content is appended.
"R" to open in random access mode. The parameter record-length is required to indicate record length.

USING
PRINT modifier to produce formatted output. PRINT USING format$ variable1,variable2... prints the values of the variables according to the content of the string format$. The rules for the format string are the same as in Microsoft CP/M Basic
  • "!" prints only the first character of the string variable
  • "\[n spaces]\" prints (n+2) characters of the string variable: one for each backslash and one for each of the n spaces. With only 2 backslashes two characters are printed.
  • "&" prints the entire string
  • "#" represents a digit in a numeric format. The numeric format is for instance "##.###" indicating two digits before the decimal point, and 3 digits after. For the digits before the decimal point, if the value of the variable does not have enough digits, the value is printed right justified by writing spaces in the place of the missing digits. If the number of digits is too large, the value is printed preceded by a &percent; sign. For the digits after the decimal point, is the number of digits exceeds the format, rounding occurs.
  • "+" before/after the "##.###" format indicates that a + or - must be printed before/after to indicate the sign of the number.
  • "-" after the numeric format indicates that a - sign should be printed if the number is negative.
  • "**" before the numeric format indicates that asterisks rather than spaces should replace the missing digits.
  • "$$" indicates that a $ sign must be printed to the left.
  • "^^^^" following a "#.#" format as in "#.##^^^^" indicates that the output should be in scientific notation 'x.xxE+nn'.
