Differences between Blassic and GW-BASIC

ATN
Calculates the arctangent. Blassic uses ATAN
BLOAD
BLOAD filename[,offset] loads a file in memory at address DEF SEG + offset. DEF SEG=&HB800 indicates the video memory. Blassic uses LOAD "filename",address[,size]
BSAVE
BSAVE filename,offset,length saves length octets starting at offset to filename. Blassic uses SAVE "filename", B, address, length
CALL
CALL numvar[(variables)] calls a machine language subroutine at numvar passing the comma separated list variables. Blassic uses USR to call functions in dynamic link libraries. .
COLOR
COLOR [foreground][,[background][,border]] defines the foreground , backgground and border colors. The behavior depends on graphic mode and video card (CGA, EGA or Hercules). Blassic sets the background color with PAPER background and the foreground color with PEN foreground
COM(n)
COM(n) ON/OFF/STOP enables or disables trapping of communications activity to the specified communications adapter. n=1,2
COMMON
COMMON variables passes the variables to the chained program
CSRLIN
returns the current line (row) position of the cursor. Blassic uses YPOS
DEF SEG
DEF SEG [=address] assigns the current segment address to be referenced by a subsequent BLOAD, BSAVE, CALL, PEEK, POKE, or USR.
DEF USR
DEF USR[n]=integer specifies the starting address of an assembly language subroutine to be called from memory by the USR function.
ERDEV($)
returns the actual value (ERDEV) of a device error, and the name of the device (ERDEV$) causing the error.
EXTERR(n)
returns MS-DOS extended error information.
  • n=0 return extended error code
  • n=1 Extended error class
  • n=2 Extended error suggested action
  • n=3 Extended error location
FRE
returns the number of available bytes in allocated string memory.
IOCTL
IOCTL[#]file number,string sends a "control data" string to a character device driver anytime after the driver has been opened.
IOCTL$
IOCTL$([#]file number) read a "control data" string from an open character device driver.
INP
reads a byte from a port. Not feasible in Blassic.
KEY
KEY key number,string expression key number is the number of the function key to be redefined. key number may range from 1-20. string expression is the key assignment. Any valid string of 1 to 15 characters may be used.
KEY ON Displays the first six characters of the key values on the 25th line of the screen.
KEY OFF Erases the key display from the 25th line
KEY(n)
initiates and terminates key capture in a GW-BASIC program.
LOCK
LOCK [#]n [,[record number] [TO record number]] restricts the access by other processes to all or part of a file that has been opened.
ON COM/KEY/PEN/PLAY/STRIG/TIMER
creates an event trap line number for a specified event (such as communications, pressing function or cursor control keys, using the light pen, or using joysticks).
OUT
OUT port,byte sends byte to a machine output port port. Not feasible in Blassic.
PALETTE
PALETTE [attribute,color] gives color to attribute. Blassic uses INK attribute, red, green, blue
PALETTE USING
PALETTE USING arrayname ( starting) gives colors defined in arrayname to attributes starting at starting . Blassic uses INK attribute, red, green, blue
PCOPY
PCOPY sourcepage, destinationpage copies one screen page to another in all screen modes.
PEN
PEN ON/OFF/STOP enables or disables the reading of optical pen.
PEN(n) reads the coordinates of optical pen
PLAY
PLAY string expression plays music by embedding a music macro language into the string data type.
PLAY(n)
returns the number of notes currently in the background music queue.
PMAP
PMAP is used with WINDOW and VIEW to translate coordinates.
POINT
POINT(x,y) is used to read the color of a point. Blassic uses TEST(x,y)
PRESET
displays a point at a specified place on the screen during use of the graphics mode. (Blassic uses PLOT)
PSET
same
SCREEN
variable=SCREEN(row,col,[,z]) the variable contains the ASCII code of the character occupying the indicated row and column. When the optional parameter z is present, and nonzero, the function returns the color of the character instead of ASCII code.
SCREEN
SCREEN [mode] selects a graphic mode
  1. SCREEN 0: text mode (MODE 0)
  2. SCREEN 1: 320x200 with 4 colors (MODE 1)
  3. SCREEN 2: 640x200 with 2 colors (MODE 2)
  4. SCREEN 7:320 x 200 with 16 colors (MODE 1)
  5. SCREEN 8 640 x 200 with 16 colors (MODE 2)
  6. SCREEN 9: 640x350 with 4 or 16 colors (MODE 10)
  7. SCREEN 10: 640x350 monochrome (MODE 10)
SOUND
SOUND freq,duration emits a sound of frequency freq for duration clock ticks. Clock ticks occur 18.2 times per second.
STICK
STICK(n) returns the x and y coordinates of two joysticks. Blassic uses XMOUSE/YMOUSE.
STRIG
STRIG(n) returns the status of the joystick trigger. Blassic uses INKEY$ or GET A$.
STRIG(n)
TIMER
Returns the number of seconds since midnight or system reset. Blassic uses TIME to get the number of seconds since Jan 1, 1970 00:00:00 UTC.
UNLOCK
UNLOCK [#]n [,[record number] [TO record number]] releases locks that have been applied to an opened file by the LOCK command. Although Unix has mandatory locks, Blassic does not implement file locking.
variable=USR [n] (argument)
calls assembly language routine number n passing argument and returns the result in variable .
VARPTR$(variable)
returns a three-byte string. The first byte indicates the type of the variable (2=integer, 3=string, 4=single precision float, 8=double precision float). The second byte contains the least significant part of the 16-bit address of the variable. The last byte contains the most significant part of the 16-bit address.
VIEW [[SCREEN][(x1,y1)-(x2,y2) [,[fill][,[border]]]]
defines a physical viewport limit from x1,y1 (upper-left x,y coordinates) to x2,y2 (lower- right x,y coordinates). When SCREEN is present, the coordinates are absolute, and points outside the view port are not drawn. Without SCREEN the coordinates become relative to the upper-left corner. fill fills the area with a color. border draws a border around the area.
VIEW PRINT [topline TO bottomline]
sets the boundaries of the screen text window. Without arguments,initializes the whole screen area as the text window. With arguments, limits the text window to lines between topline (≥1) and bottomline (<25) .
WAIT
WAIT port number, n[,j] suspends program execution while monitoring the status of a machine input port.
WINDOW
